Copy files to a new PC: preview first, avoid /MIR

Short answer

Windows has a built-in copier, Robocopy, that can show what it plans to do. Run it once with /L (list only) and read the source and destination carefully. If the plan is right, remove /L to copy. /E copies subfolders without deleting destination extras, but can overwrite same-name files. /MIR also deletes destination extras.

Follow along and try it step by step. You make a small made-up folder pair, run each command yourself, and see the real recorded result.

Common mistakes

  1. Using /MIR to move files to a new PC. /MIR makes the destination an exact mirror of the source, which means it deletes everything in the destination that is not in the source. One forum answer calls it a faster copy; it is a copy plus deletion of destination extras.
  2. Reading exit code 1 as a failure. Most programs use 0 for success and anything else for failure. Robocopy is different: 1 means files were copied, 0 means there was nothing to do, and only 8 or more means a real failure.
  3. Skipping the /L dry run. The plan costs nothing and changes nothing. If the folders are wrong, the plan shows it while there is still nothing to undo.
  4. Practising on your real folders. Make a small made-up folder pair first, like the one in this lesson. Get the habit there, then use it on the real move.
  5. Thinking /E means no data can be lost. It does not delete extra destination files, but it can overwrite same-name files. In particular, without /XO it can replace a newer destination copy with an older source copy. Check the plan and back up the destination first.

Frequently asked questions

Did exit code 1 mean my copy failed?

No. Robocopy's exit codes are unusual: 0 means nothing needed copying, 1 means files were copied, 2 means extra files exist in the destination, 3 means both, and 8 or more means a real failure. The recording shows all of these except the failure range.

What is the difference between /E and /MIR?

/E includes every subfolder, including empty ones. It copies new or different files and can overwrite same-name destination files. /MIR includes /E plus /PURGE: it also deletes destination files and folders absent from the source.

Can a plain copy delete my old files?

The commands shown with /E do not delete source files or extra destination files. They can still overwrite files with the same names. This is not a no-data-loss guarantee: inspect /L, keep separate backups, and never add /MOV, /MOVE, /PURGE or /MIR unless their effects are intended.

The report scrolled past too fast. How do I keep it?

Add /LOG:plan.txt to the command and Robocopy writes the same report to a file you can open in Notepad. Add /L as well and the file holds only the plan, with nothing copied.

Does this work on both Windows 10 and Windows 11?

Yes. Robocopy is built into Windows and has been for years, and the options in this lesson behave the same on both. That makes it handy for the move from a Windows 10 PC to a Windows 11 one.

Does exit code 0 prove the copied files are byte-identical?

No. It means Robocopy found no work or copy failure under the options and file-selection rules used. This lesson does not hash the copied file contents. A separate hash check is needed for byte-level integrity.
